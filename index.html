Minecraft Java Edition

⛏ Как зайти на сервер

  1. Запусти Minecraft Java Edition версии 1.21.4.
  2. Открой раздел «Сетевая игра».
  3. Нажми «Добавить сервер».
  4. Введи IP-адрес сервера.
  5. Нажми «Готово» и выбери YukaiWorld.
Сервер пока разрабатывается. IP появится после открытия!
